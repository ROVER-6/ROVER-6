<h3 align="center">About me:</h3>

###

<p align="left">When I was 12 years old, I remember downloading some dodgy cheats for Roblox on my PC. After a few months or so after using these dodgy cheats, I thought to myself: "Why don't I try make my own?". At the time, it seriously wasn't hard, as there were so many libraries that made it very possible to make these cheats. I downloaded Visual Studio, watched some tutorials and at the end of the day, had my own working Roblox cheats. I felt like Linus Torvalds, honestly it was incredible. Looking back now, it seriously wasn't impressive, I just referenced some dodgy library in C# and used its functions, but it honestly made me feel awesome.<br><br>After "developing" these cheats, I kept on learning C#, expanding my knowledge on UI design and what-not. I made some actually nice looking interfaces, and actually wrote some decent code to go along with these interfaces. I never really released anything, however, as I was too embarrassed to do so.<br><br>I put programming down for a while, but picked it up in school, when I studied computer science. As I had to study Python for my exams. Luckily, I already knew a solid chunk of Python since I had made Discord bots in Python using the discord.py library in the past.<br><br>At this time, I also got into game hacking, learning how to reverse games for offsets and whatnot, reading and writing memory, etc. This is when I started learning C++. I never really got into C++, and haven't used it in a while, and don't plan on really using it.<br><br>Nowadays, I really only use high-level languages, such as C#, Python.
